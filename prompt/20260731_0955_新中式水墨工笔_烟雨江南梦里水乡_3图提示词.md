# 《烟雨江南·梦里水乡》新中式水墨工笔生图提示词

> **原典意境**：“烟雨江南，梦里水乡。”
> **意境解读**：细雨蒙蒙，水墨氤氲。白墙黛瓦的古镇错落于青碧水网之间，乌篷船划过小桥流水，湿润的空气中弥漫着诗意与恬静，犹如梦境般的江南画卷。
> **视觉流派**：新中式水墨与宋代工笔绢本相融，淡墨渲染、青灰与黛蓝中性色调，极致的极简留白与烟雨光雾感。
